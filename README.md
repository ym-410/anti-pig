# Anti Pig

自己管理を目的とした、Flask製のシンプルな家計簿アプリです。支出・収入を登録し、月ごとの合計や明細を確認できます。

## 主な機能

- 支出・収入の登録
- 選択した収支区分に応じたカテゴリーの切り替え
- 入力金額への8%・10%の税込計算
- 入力日付への当日の日付の自動設定
- 月ごとの支出・収入・収支の集計
- カレンダー画面での支出・収入明細の切り替え
- 月ごとのカテゴリー別支出・収入を円グラフで表示

収支区分は、データベース上で次の値として保存されます。

| 値 | 区分 |
|---:|---|
| `0` | 支出 |
| `1` | 収入 |

## 必要な環境

- Python 3
- Flask 3.1.3

## セットアップ

リポジトリのディレクトリで仮想環境を作成し、依存パッケージをインストールします。

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

Windows PowerShellでは、仮想環境を次のコマンドで有効化します。

```powershell
.venv\Scripts\Activate.ps1
```

## 起動方法

```bash
python app.py
```

起動後、ブラウザで `http://127.0.0.1:5000` を開きます。

初回起動時に、プロジェクト直下へSQLiteデータベース `antipig.db` と `transactions` テーブルが自動作成されます。

## 使い方

### 入力画面

`/` では、支出または収入を登録できます。

1. 支出・収入タブを選択する
2. 日付、メモ、金額を入力する
3. カテゴリーを選択する
4. 「登録」を押す

支出・収入タブを変更すると、選択できるカテゴリーも切り替わります。8%・10%ボタンを押すと、入力中の金額へ税率を適用し、小数点以下を切り捨てます。

### カレンダー画面

`/calendar` では、指定した月の合計と明細を確認できます。

- 月を指定して「表示」を押すと対象月が切り替わります。
- 上部に支出合計、収入合計、収支が表示されます。
- 支出・収入タブで表示する明細を絞り込めます。
- 表示対象の明細がない日の日付見出しも非表示になります。

### グラフ画面

`/graph` では、指定した月の支出・収入をカテゴリー別の円グラフで確認できます。

- 月を指定して「表示」を押すと対象月が切り替わります。
- 支出・収入タブで表示するグラフを切り替えられます。
- 凡例にはカテゴリーごとの金額と構成比が表示されます。
- 対象月に記録がない場合は、その旨を示すメッセージが表示されます。

## ディレクトリ構成

```text
antipig_py/
├── app.py                  # Flaskアプリとルーティング
├── db_handle.py            # SQLiteの作成・登録・取得・集計
├── requirements.txt        # Python依存パッケージ
├── static/
│   ├── script.js           # 入力補助とタブ切り替え
│   └── style.css           # 画面スタイル
└── templates/
    ├── index.html          # 入力画面
    ├── calendar.html       # 月別明細画面
    └── graph.html          # 月別カテゴリー円グラフ画面
```

## データベース

`transactions` テーブルには次の情報が保存されます。

| カラム | 内容 |
|---|---|
| `id` | レコードID |
| `amount` | 金額 |
| `category` | カテゴリー |
| `date` | 日付 |
| `memo` | メモ |
| `is_income` | 支出・収入区分 |

## 現在の制約

- 登録後は入力画面へ戻るため、選択していた日付と支出・収入タブは初期状態に戻ります。
- 登録済みデータの更新・削除は未実装です。
- 開発サーバーは `debug=True` で起動するため、公開環境でそのまま使用しないでください。
