# Anti Pig

Anti Pigは、日々の支出と収入を記録し、月別の明細やカテゴリー別の内訳を確認できるシンプルな家計簿Webアプリです。Flask、SQLite、HTML/CSS、JavaScriptで構成されています。

## 主な機能

- 支出・収入の登録・編集・削除
- 入力金額の8%・10%税込計算（小数点以下切り捨て）
- 入力日への当日の日付の自動設定
- 月別明細の支出・収入切り替え
- カテゴリー別金額と構成比の円グラフ表示
- カテゴリーごとの直近12か月の推移を棒グラフで表示

収支区分は、データベースに次の値で保存されます。

| 値 | 区分 |
| ---: | --- |
| `0` | 支出 |
| `1` | 収入 |

## 使用技術

- Python 3
- Flask 3.1.3
- SQLite
- HTML / CSS
- JavaScript
- Gunicorn

円グラフと棒グラフは外部ライブラリを使わず、HTML/CSSとJavaScriptで描画しています。円グラフは集計データからCSSの`conic-gradient()`を生成します。

## セットアップ

### macOS / Linux

```bash
python3 -m venv .venv
source .venv/bin/activate
python3 -m pip install -r requirements.txt
```

### Windows PowerShell

```powershell
py -m venv .venv
.venv\Scripts\Activate.ps1
py -m pip install -r requirements.txt
```

## 起動方法

開発サーバーを起動します。

```bash
python3 app.py
```

Windowsでは、環境に応じて`python3`を`py`または`python`に読み替えてください。

起動後、ブラウザで次のURLを開きます。

```text
http://127.0.0.1:5000
```

初回起動時に、プロジェクト直下へ`antipig.db`が作成され、その中に`transactions`テーブルが自動作成されます。

## 画面と使い方

### 入力画面（`/`）

支出または収入を登録する画面です。

1. 「支出」または「収入」を選択する
2. 日付、メモ、金額を入力する
3. カテゴリーを選択する
4. 「登録」を押す

支出・収入を切り替えると、選択できるカテゴリーも切り替わります。

| 支出カテゴリー | 収入カテゴリー |
| --- | --- |
| 食費、日用品、衣服、交際費、嗜好品、ガソリン代、ガジェット、公共、美容、医療費、交通費、車 | 給与、仕送り、臨時収入、その他 |

金額入力欄の「8%」「10%」ボタンは、入力中の金額へそれぞれ`1.08`または`1.1`を掛け、小数点以下を切り捨てます。

### カレンダー画面（`/calendar`）

指定した月の収支と明細を確認する画面です。

- 初期表示では現在の月が選択されます。
- 月を変更して「表示」を押すと、対象月の情報を取得します。
- 支出合計、収入合計、両者の差額である収支を表示します。
- 「支出」「収入」タブで明細を絞り込みます。
- 明細は日付の新しい順、同じ日付では登録順の新しいものから表示します。
- 明細を選択すると編集画面へ移動します。

### 編集画面（`/transactions/<取引ID>/edit`）

登録済みの支出・収入を編集または削除する画面です。

- 登録済みの収支区分、日付、メモ、金額、カテゴリーがフォームへ表示されます。
- 内容を変更して「更新」を押すと、対象データを更新して該当月のカレンダーへ戻ります。
- 「削除」を押すと、対象データを削除して該当月のカレンダーへ戻ります。

### グラフ画面（`/graph`）

指定した月のカテゴリー別内訳を確認する画面です。

- 初期表示では現在の月が選択されます。
- 「支出」「収入」タブで表示対象を切り替えます。
- カテゴリー別の合計金額を円グラフで表示します。
- 凡例にはカテゴリー名、合計金額、構成比を表示します。
- 円グラフの凡例からカテゴリーを選択すると、選択月を含む直近12か月の金額推移を棒グラフで表示します。
- 記録がない月は`0円`として表示します。
- 棒グラフには、選択したカテゴリーの円グラフと同じ色を使用します。
- 棒グラフの月は`09月`の形式で表示します。
- 棒グラフは横スクロールに対応し、開いたときは最新月のある右端を表示します。
- 対象月に記録がない場合はメッセージを表示します。

## URL一覧

| URL | メソッド | 内容 |
| --- | --- | --- |
| `/` | `GET` | 入力画面を表示 |
| `/` | `POST` | 支出または収入を登録 |
| `/calendar` | `GET` | 月別の収支と明細を表示 |
| `/graph` | `GET` | 月別のカテゴリー円グラフと月別推移を表示 |
| `/api/category-trend` | `GET` | 指定カテゴリーの直近12か月の集計結果をJSONで返す |
| `/transactions/<取引ID>/edit` | `GET` | 編集画面を表示 |
| `/transactions/<取引ID>/edit` | `POST` | 登録済みデータを更新 |
| `/transactions/<取引ID>/delete` | `POST` | 登録済みデータを削除 |

`/calendar`と`/graph`では、`month=YYYY-MM`形式のクエリパラメーターで対象月を指定します。

```text
/calendar?month=2026-08
/graph?month=2026-08
```

### カテゴリー別推移API

`/api/category-trend`は、棒グラフの描画に使用する月別集計データを返します。

| パラメータ | 内容 | 例 |
| --- | --- | --- |
| `month` | 推移の基準月 | `2026-08` |
| `category` | 取得するカテゴリー | `食費` |
| `is_income` | 支出は`0`、収入は`1` | `0` |

リクエスト例：

```text
/api/category-trend?month=2026-08&category=食費&is_income=0
```

レスポンス例：

```json
{
  "category": "食費",
  "months": ["2025-09", "2025-10", "2025-11", "2026-08"],
  "amounts": [32500, 31800, 36100, 52300]
}
```

`months`と`amounts`は同じ位置同士が対応します。実際のレスポンスには12か月分の値が含まれます。

## データベース

データはSQLiteの`transactions`テーブルへ保存されます。

| カラム | 型 | 制約 | 内容 |
| --- | --- | --- | --- |
| `id` | `INTEGER` | 主キー・自動採番 | レコードID |
| `amount` | `INTEGER` | `NOT NULL` | 金額 |
| `category` | `TEXT` | `NOT NULL` | カテゴリー |
| `date` | `TEXT` | `NOT NULL` | 日付 |
| `memo` | `TEXT` | `NOT NULL` | メモ |
| `is_income` | `INTEGER` | `NOT NULL` | 支出・収入区分 |

## バックアップ

バックアップには`sqlite3`コマンドが必要です。インストールされていることを次のコマンドで確認できます。

```bash
sqlite3 --version
```

プロジェクト直下でバックアップスクリプトを実行します。

```bash
./backup.sh
```

`backups/YYYY-MM-DD_HHMMSS.db`という名前で、実行時点のデータベースが保存されます。バックアップ先ディレクトリの権限は`700`、バックアップファイルの権限は`600`に設定されます。

`antipig.db`と`backups/`は`.gitignore`の対象です。家計簿データとそのバックアップはGitHubへアップロードされません。

## 現在の制約

- ユーザー登録やログイン機能はありません。
- 入力値に対するサーバー側の詳細なバリデーションや独自のエラー表示は未実装です。
- 登録後は入力画面へ戻るため、選択していた日付や収支区分は初期状態へ戻ります。
- SQLiteファイルはアプリを実行したカレントディレクトリに作成されます。
- `app.py`は`debug=True`で起動するため、開発用途を想定しています。公開環境ではそのまま使用しないでください。
